# Reproduction guide (expanded benchmark)
Environment: Linux x86-64, 8 threads, ~31 GB RAM; micromamba envs `vt` (htslib/samtools/bcftools 1.21, numpy) and `hp` (hap.py 0.3.15, python 2.7) under `~/varion_mamba`; `bwrap`. Details: `independent_genome/ENVIRONMENT.md`.
1. **Frozen R2:** `research/final_validation/expanded/verify_identity.sh` must print OK for HEAD 3cdfe5a, 21 sources, binary sha256 `6c675174854917ca3bbbfc1192c9205ac0043a696bd37d6ff2b2c08c3a3304be`, model `649215d52e57cf00d9f69b8631d7c0d9a1848db2550fc593b7d464c1b4cab6ac`. Build recipe: `research/stage4/R2_LOCK.md` (out-of-tree rebuilds need `HTS_INC/HTS_LIB` overrides).
2. **Data:** truth/BED/reference per `expanded_benchmark_preregistration.md` §1. HG007 natives: `research/final_validation/fetch_hg007.sh`. HG001: `expanded/fetch_hg001_nvme.sh chr17 chr19` (source URL file `/mnt/hdd/AI_DNA_ANALYZER_hg001/logs/source_url.txt`); check BED-mean depth against `meta/*_native_cov.json`.
3. **Callers + scoring:** `SAMPLE=HG001 BAMDIR=~/varion_data/hg001_bam python3 expanded/run_expanded.py chr17 15 101` (HG007: omit BAMDIR); `expanded/matrix_expanded.sh SAMPLE CONTIG [dv]`; queue used: `expanded/queue.sh`. Results append to `expanded/RESULTS.jsonl` (commands, hashes, rusage per run).
4. **DeepVariant:** `~/varion_data/dv/pull.sh` (layers sha256-verified; manifest sha256:962e5a83b1d76aae6990625d47102785f791603f2138aa1fa9aa4fb6a2eecbe6) then `matrix_expanded.sh SAMPLE CONTIG dv`.
5. **Analysis:** `expanded/hg007_existing_blocks.py` (once), then `~/varion_mamba/envs/vt/bin/python expanded/analyze_expanded.py` → `expanded_results.csv`, `expanded_runtime_memory.csv`, `BOOTSTRAP_EXPANDED.tsv`, `ENDPOINTS_EXPANDED.md`, `DEEPVARIANT_TABLE.md`.
Expected: all F1 within the deterministic callers' exact values (R2/R1.1 VCFs are deterministic; downsampling by `samtools view -s SEED.FFFF`). Wall/CPU vary run to run.
Open item for a third party: raw natives (HG001 ~25 GB, HG007 ~10 GB) are not in the repo; they are re-fetchable from GIAB.
